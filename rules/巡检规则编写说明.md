# 巡检规则编写说明

## 规则文件格式

每条规则保存为一个 `.json` 文件，放在 `rules/inspection/` 目录下。

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| name | 是 | 规则名称 |
| category | 否 | 分类（如：制动系统、驾驶模式、通信系统） |
| system | 是 | 目标系统名（必须与解析系统名一致） |
| severity | 是 | 严重级别：`critical` / `warning` / `info` |
| type | 是 | 检查类型：`single_frame`（单帧） |
| logic | 是 | 条件逻辑：`and`（全部满足）/ `or`（任一满足） |
| conditions | 是 | 条件数组 |
| message | 否 | 命中时的提示消息 |
| suggestion | 否 | 建议处理方式 |

## conditions 条件格式

| 字段 | 说明 |
|------|------|
| field | 字段名（必须与解析后的字段名完全一致） |
| op | 比较运算符：`eq`(等于) / `neq`(不等于) / `gt`(大于) / `lt`(小于) / `gte`(大于等于) / `lte`(小于等于) / `contains`(包含) |
| value | 目标值 |

## 示例

### 单条件
```json
{
    "name": "ATP紧急制动检查",
    "category": "制动系统",
    "system": "ATP应用",
    "severity": "critical",
    "type": "single_frame",
    "logic": "and",
    "conditions": [
        {"field": "已输出EB标志位", "op": "eq", "value": "1"}
    ],
    "message": "ATP输出了紧急制动",
    "suggestion": "检查紧急制动原因"
}
```

### 多条件（AND）
```json
{
    "name": "AM模式下ATO故障",
    "system": "ATP应用",
    "severity": "critical",
    "type": "single_frame",
    "logic": "and",
    "conditions": [
        {"field": "当前驾驶模式", "op": "eq", "value": "AM"},
        {"field": "ATO板级故障", "op": "eq", "value": "1"}
    ],
    "message": "AM模式下ATO发生板级故障",
    "suggestion": "检查ATO板卡状态，考虑降级为CM模式"
}
```

### 数值比较
```json
{
    "name": "列车超速",
    "system": "ATP应用",
    "severity": "critical",
    "type": "single_frame",
    "logic": "and",
    "conditions": [
        {"field": "列车当前速度值", "op": "gt", "value": "80"}
    ],
    "message": "列车速度超过80km/h",
    "suggestion": "检查速度传感器数据和限速曲线"
}
```
